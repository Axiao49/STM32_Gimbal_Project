# STM32_Gimbal_Project

1、板子与平台：芯片：STM32F103C8T6，平台：暂时为Keil
2、硬件与功能：
     LED灯：LED1指示系统运行异常与否，LED2指示当前模式，LED3翻转代表指令接收
     按键：抖动：时间<50ms，不做反应；短按：时间50ms~1s，切换到下一模式（1-2-3-1）；长按：时间>1s,回到上一模式
     OLED：显示工作室名称、当前模式、最近一次按键事件类型（短按/长按）、最近一次收到的有效指令、MPU6050运行异常状态、姿态板角度与舵机运动角度
     云台：模式一：通过串口发送指令可驱动云台运动；模式二：姿态板随动；模式三：追光运动   
     MPU6050：姿态读取，对应模式二
     四光明矩阵传感器：采样读数，对应模式三
